# 🚀 Projeto de Pesquisa — Acompanhamento TEA

Sistema desenvolvido para auxiliar no acompanhamento de terapias multifuncionais voltadas ao Transtorno do Espectro Autista (TEA).  
Focado em organização, acessibilidade e suporte ao trabalho clínico e familiar.

## 📌 Sobre o Projeto

O sistema permite gerenciar informações de pacientes em acompanhamento terapêutico, ajudando profissionais e responsáveis a manterem um histórico completo e acessível ao longo do tratamento.

- JavaScript
- CSS3
- Git & GitHub


## ✅ Funcionalidades
